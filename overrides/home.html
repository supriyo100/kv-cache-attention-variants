Inference engineering, from tokens to GPU systems

A large model answers one token at a time, and every token re-reads everything the model has seen. Serving it well is a memory problem first: where each byte of the KV cache lives, who shares it, when it moves, and what the GPU waits on. This notebook works through it one step at a time, with the derivation, a diagram, tested code and the trade-offs for each idea.
